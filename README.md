# NewsHub

NewsHub е уеб приложение за новини, създадено с Django.

## Функционалности

- Създаване, преглеждане, редактиране и изтриване на новини
- Страница с последните 3 новини
- Категории и тагове към новините
- Търсене по заглавие и съдържание
- Филтриране по категория или таг
- Странициране на списъка с новини
- Коментари и отговори към коментари
- Редактиране и изтриване на коментари и отговори
- Създаване и преглед на категории и тагове през сайта

## Изисквания

- Python
- Django, посочен във файла `requirements.txt`

## Стартиране в Windows PowerShell

Отвори PowerShell в папката на проекта и изпълни командите поред:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Приложението стартира и без зададена променлива `DJANGO_SECRET_KEY`, като използва локален ключ по подразбиране. По желание можеш да зададеш собствен ключ в PowerShell преди стартиране:

```powershell
$env:DJANGO_SECRET_KEY = "твоят-локален-ключ"
```

Подготви базата данни и стартирай приложението:

```powershell
python manage.py migrate
python manage.py runserver --insecure
```

Отвори приложението на <http://127.0.0.1:8000/>.

## Django Admin (по избор)

Административният панел е на <http://127.0.0.1:8000/admin/>. Той не е необходим за използването на сайта. Категории и тагове могат да се създават от навигацията.

Ако искаш да използваш админ панела локално, създай администратор с:

```powershell
python manage.py createsuperuser
```

## Приложения

- `news` — новини и формата за новина
- `comments` — коментари и отговори
- `catalog` — категории и тагове
